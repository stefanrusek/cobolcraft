- [x] T59700 [bugguiitems] Root cause: UI-SLOT (client/src/ui-render.cob) drew every item that is not a code-drawn kind as ONE quad of the sprite ITEM-SPRITE-OF found, and for a block item (the item definition names `minecraft:block/<id>`, a model with elements) that sprite is the up face (else the first face) of the model's first element. The model's elements, its `display.gui` transform (block/block: rotation (30, 225, 0), scale 0.625) and `gui_light` were never read for the GUI, so planks, slabs, cobblestone and logs were a flat square (a slab and the planks identical; a log only its end rings). Slots are the only item-icon path (hotbar, inventory, crafting grid and result, containers, creative and recipe-book lists, trade list, cursor stack, drag preview: all WK-SLOT widgets drawn by UI-SLOT), so one fix covers them. Client only: not core, not shim.
