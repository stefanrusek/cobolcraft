## Lane 002-lane-p45h (T34000+; performance of chunk generation with the structure starts of lane p45f)

Operator report: test_struct_jigsaw_real ran more than 10 CPU minutes on the p45f branch (242 s user on p45a's build); the game is judged by chunk loading speed. Measured with `core/tests/test_struct_beard_cost.cob` (standard world, seed 12345, production gates, CC_GENERATED_DIR of the real packs, atomic path, process CPU time of `clock()`, machine under load average 20 to 65): a chunk of a 2 x 2 or 3 x 3 block around the first village or outpost start cost 26.8 s CPU, a chunk with no adapting start within 9 chunks 1.7 s, and the same near chunks with STRUCT-BEARD-PREPARE not called 1.7 s. STRUCT-BEARD-PREPARE itself is not the cost (1.5 s once for the first village's start, then 0.4 to 34 ms per chunk: the start list cache, the store and the generator memo answer it).
