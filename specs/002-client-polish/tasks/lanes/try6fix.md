## Lane 002-lane-try6fix (T6400+)

Operator play of try6 (release build of 918ed359, standard-format world).

- [x] T6400 Every ocean frozen: `BIOMES-OPEN` (core/src/block-props.cob) read the climate of a biome only from network NBT of at most 4096 bytes, but the entries of a standard set are strict JSON of some 6000 bytes, so every biome of a standard world kept temperature 0 and no precipitation, and `freeze_top_layer` (35 part 5 section 8, ice below 0.15) froze every water surface. `BIOME-CLIMATE-JSON` (core/src/biome-climate.cob) reads has_precipitation, temperature and temperature_modifier from the JSON entry; the payload area is 64 KiB. Tests: `core/tests/acc_biome_climate_standard.cob` (red: `scratchpad/try6fix/red-climate.txt`; skipped without the generated packs), `core/tests/test_biome_climate_json.cob`.
- [x] T6401 Blocks that have no collision could not be broken (torch, mushrooms, grass and tall grass, sugar cane, flowers, saplings, vines): the client targets them correctly (`RAYCAST` hits the outline shape, `BSH-OUT-ID`; a no-collision block keeps a full or authored outline), but `BLOCK-ACTION` (core/src/breaking.cob) treated a hardness of 0 as unbreakable and answered Start Digging with the block's old state, in survival and in creative. Only the void and hardness below 0 are refused now; hardness 0 breaks at once on Start (survival leaves the item, creative none). Supersedes the "torch breaking" item of draft ticket CC-0009. Test `core/tests/test_break_instant.cob` (red: `scratchpad/try6fix/red-break-instant.txt`).
- [x] T6402 Food: the item rows of a standard set name the food component ("food apple", "food Foods.COOKED_BEEF", "food {6,1.2,true}") but `IT-FOOD` (core `content-tables.cob`) and the client's `CL-ITEM-INFO` read a number after "food ", so no item was a food and right-click did nothing. `CONTENT-FOOD` (content/src/foods.cob, the Foods table of 25 part 1 section 8.2 and the inline form) gives nutrition, saturation, always-edible and use time (32 ticks, dried kelp 16, honey bottle 40); `IT-FOOD-SAT/-ALWAYS/-TICKS` in CITEMS.cpy; `hunger.cob` eats with the item's time, adds nutrition and saturation (up to the food level), and at food 20 only a can_always_eat food starts eating. Creative still does not eat (unchanged). Effects of eaten foods (golden apple regeneration, rotten flesh hunger, chorus teleport, milk) are not applied: next run. Tests `content/tests/test_content_food.cob` (red: `scratchpad/try6fix/red-content-food.txt`), `core/tests/acc_eat_standard.cob` (red: `scratchpad/try6fix/red-eat.txt`).
- [x] T6403 Wheat planted wheat: the generated item rows link an item to the block of the same key, so the item `wheat` (class Item) placed the crop block `wheat` while `wheat_seeds`, carrot, potato, beetroot_seeds, melon_seeds, pumpkin_seeds, torchflower_seeds, pitcher_pod, cocoa_beans, string and redstone (block items whose block has another name) placed nothing. `core/src/content-tables.cob`: an item of class Item places nothing; `ITEM-PLACED-BLOCK` names the block of those block items. Checked against all 1659 rows: wheat is the only plain Item with a link; melon slice, pumpkin pie, beetroot and apple place nothing. Tests `core/tests/acc_place_items_standard.cob` (red: `scratchpad/try6fix/red-place-items.txt`), `core/tests/test_item_placed_block.cob`.
- [x] T6404 Doors and tall plants: placing a lower half (property half = lower) places only that half and each half could be broken alone. `core/src/double-block.cob` (`DOUBLE-HALF`, `DOUBLE-PLACE-FITS`, `DOUBLE-PLACE-UPPER`, `DOUBLE-BREAK`): `BLOCK-PLACE` refuses the placement unless the cell above is empty or replaceable (and inside the dimension), then places both halves; breaking either half (survival `BREAK-FINISH`, creative `BLOCK-ACTION`) removes both and drops once, with the loot of the lower half. Door facing and hinge stay CC-0009. Test `core/tests/acc_door_standard.cob` (red: `scratchpad/try6fix/red-door.txt`).
