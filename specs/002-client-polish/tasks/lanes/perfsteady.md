Operator report on try16 (db901a9a, release build): "really bad" performance, the operator gave up testing (earlier: village very laggy, 44 fps in a stronghold, 0 fps for the first minute after a load or a respawn (lane bugstall), shaking over height differences (lane bugstep)).
